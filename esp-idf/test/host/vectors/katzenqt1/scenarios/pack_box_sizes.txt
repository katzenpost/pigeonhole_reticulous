# Packing fills a box up to the size the transport writes: 256 bytes on a mesh, 1549 on the
# mixnet. No box is longer, and the next message goes to a box of its own.

create alice g
join bob g
run
invite alice g bob
run
box-size alice 256
hold alice
repeat 20 send alice g a short message of about thirty
jobs alice g
----

message to next box, 71 bytes

release alice
